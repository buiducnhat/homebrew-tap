# homebrew-tap

Homebrew tap for [buiducnhat](https://github.com/buiducnhat)'s tools.

## Usage

```sh
brew install buiducnhat/tap/lazytools
```

Formulae in this repository are generated and updated automatically by
[dist](https://github.com/axodotdev/cargo-dist) when a release is tagged.
Edits made here by hand will be overwritten by the next release.
